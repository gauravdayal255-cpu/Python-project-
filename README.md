# मेरे पायथन प्रोजेक्ट

पायथन सीखते हुए बनाए गए छोटे प्रोजेक्ट।

| फ़ाइल | क्या करता है |
|---|---|
| `task_list.py` | 3 टास्क लेकर फ़ाइल में सेव करता है |
| `calculator.py` | फंक्शन से बना कैलकुलेटर (+, -, *, /, ^) |
| `number_game.py` | 1 से 100 का नंबर 7 कोशिश में पकड़ने का गेम |
| `kharcha.py` | खर्चे लिखकर कुल हिसाब निकालता है |
| `contact_book.py` | क्लास वाली कॉन्टैक्ट बुक: जोड़ो, खोजो, हटाओ |

## चलाने का तरीका
```
python calculator.py
```
